# Metrics

The core methods of the platform are the EventRepository.getKPIs() and EventRepository.getMetricTimeseries().

## EventRepository.getKPIs()

POST /analytics/kpis
Input:
- domains (string[]): Domain or list of domains to analyze.
- from (iso8601): Start of the selected period (iso8601).
- to (iso8601): End of the selected period.
  Output, objet with:
- users_count — Number of distinct users who visited the selected domain(s).
- sessions_count — Total number of browsing sessions.
- pageviews_count — Total number of pageview events.
- events_count — Total number of tracked events.
- pageviews_per_session_avg — Average number of pageviews per session.
- duration_per_session_avg — Average active engagement time per session.
- engagement_rate — Percentage of sessions that meet the engagement criteria.
- conversion_rate — Percentage of sessions that completed at least one conversion, where conversion is converted when it contains at least one event (excluding view, engagement, checkout, purchase, interaction)
- conversions_count — Total number of completed conversion events.
- transactions_count — Total number of completed transactions.
- revenue_sum — Total revenue generated by transactions, normalized on USD using usd_rate.
- revenue_per_transaction_avg — Average revenue per transaction.

## EventRepository.getMetricTimeseries()

POST /analytics/timeseries
Input:
- metric (string): Metric to calculate over time, chosen between the supported values exposed by getKPIs.
- domains (string[]): Domain or list of domains to analyze.
- from (iso8601): Start of the selected period (iso8601).
- to (iso8601): End of the selected period.
- interval (string) — Time grouping, hour, day, week, month.
  Output, array of objects with:
- timestamp — Start of the bucket.
- value — Metric value calculated for that bucket.
