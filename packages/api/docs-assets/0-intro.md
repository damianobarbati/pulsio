# Intro

Pulsio API powers account management, website setup, billing, analytics, and event collection.

- Most endpoints accept JSON request bodies and return JSON responses.
- The event collection endpoint accepts `application/json` or `text/plain` and returns `204 No Content`.
- HTTP status codes and JSON error responses indicate request failures.
- Account endpoints use cookie-based sessions. Pulsio does not use API keys or bearer tokens.
